# Bing Keywords Consolidated

Date: `2026-04-23`

These keywords came from the Bing Webmaster exports in this folder and were de-duplicated by keyword with impressions summed across files.

## Verdict

Yes, there are usable keywords here.

The strongest buckets are:

- core CV builder intent
- CV examples and templates
- transitievergoeding calculator intent
- competitor and comparison intent

The weakest bucket is:

- noisy or misleading terms that look like `cv`, but are unrelated or too navigational

## Best Keywords To Keep

### 1. Core builder terms

These are high-fit for WerkCV and already close to the product.

- `cv maken`
- `cv maker`
- `cv maken gratis`
- `gratis cv maken`
- `curriculum vitae`
- `cv opstellen`
- `hoe maak je een cv`
- `cv maken online`

### 2. Template and example terms

These match your existing example and template architecture well.

- `cv template`
- `template cv`
- `cv voorbeeld`
- `voorbeeld cv`
- `voorbeelden cv`
- `cv maken voorbeeld`

### 3. Format and structure terms

These are worth keeping because they sit between informational and conversion intent.

- `cv format`

`cv format` is the clearest gap in this export. You have Dutch opmaak pages and an English `netherlands-cv-format` page, but no exact Dutch `cv format` landing.

### 4. Tool terms

The transitievergoeding cluster is absolutely worth targeting and defending.

- `transitievergoeding berekenen`
- `transitievergoeding`
- `transitievergoeding 2026`
- `ontslagvergoeding berekenen`
- `berekening transitievergoeding`
- `berekenen transitievergoeding`
- `berekening transitievergoeding 2026`
- `berekenen transitievergoeding 2026`
- `bereken transitievergoeding 2026`

`ontslagvergoeding berekenen` is the main content gap in this cluster. The current tool should explicitly carry that synonym in headings, intro copy, FAQ, and metadata.

### 5. Comparison and competitor terms

These are targetable, but only through comparison, alternative, and cancellation angles.

- `canva cv`
- `canva cv maken`
- `cv maken canva`
- `europass cv`
- `cv.nl`
- `cvster`
- `cv ster`
- `cvmaker`

These are not the same as builder head terms. They belong in:

- `WerkCV vs ...` pages
- `... opzeggen` pages
- `Canva vs CV builder` style guides

## Keywords To Treat Carefully

These are relevant, but user expectation may be misaligned with the actual product model.

- `gratis cv maken zonder kosten`
- `cv maken gratis downloaden`
- `gratis cv maken en downloaden`
- `gratis cv maken zonder kosten en downloaden`
- `cv gratis`

Reason:

- these users often expect a fully free PDF download
- WerkCV is better positioned as `free to start` and `pay on PDF`
- these can still be targeted, but only with very transparent copy

So these are valid defensive keywords, not the best primary acquisition set.

## Keywords To Ignore

These are not worth planning around.

- `feenstra cv onderhoud`
- `cv ketel`
- `cv.nl inloggen`
- `cvmaker inloggen`
- `c.v.`
- `c.v`

Reason:

- irrelevant non-CV intent
- pure login / navigational intent
- punctuation variants with no planning value

## Low-Volume Exploratory Terms

Not priority now, but worth keeping in a parking lot.

- `cv maker ai`
- `cv creator`
- `enhance cv`

These are only interesting if you later want:

- an AI-first CV builder positioning page
- more English SEO around improving a resume/CV

## Clear Gaps From This Export

These are the most useful planning takeaways.

1. `cv maker`
Current coverage exists, but the exact-match intent is not as cleanly owned as `cv maken`.

2. `cv format`
This looks like the strongest obvious Dutch gap.

3. `ontslagvergoeding berekenen`
This should be folded into the transitievergoeding tool cluster.

4. Free-download expectation terms
These should only be targeted if the copy is explicit about when payment happens.
