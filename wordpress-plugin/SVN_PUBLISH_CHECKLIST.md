# WerkCV Salaris Tools SVN Publish Checklist

## 1. Wait for SVN access

WordPress.org said access can take up to 1 hour after approval.

Repo URLs:

- SVN: `https://plugins.svn.wordpress.org/werkcv-salaris-tools`
- Public: `https://wordpress.org/plugins/werkcv-salaris-tools`

## 2. Generate your SVN password

In your WordPress.org profile:

- Account & Security
- Generate or update the SVN password

Use:

- Username: `rdhinesh17`
- Password: your SVN password, not your email

## 3. Install an SVN client

On Windows, TortoiseSVN is the easiest option.

If you prefer CLI, install `svn` and verify:

```powershell
svn --version --quiet
```

## 4. Package the plugin

From repo root:

```powershell
powershell -ExecutionPolicy Bypass -File .\wordpress-plugin\package-plugin.ps1
```

This creates:

- `wordpress-plugin/dist/werkcv-salaris-tools-0.1.1-review.zip`
- `wordpress-plugin/dist/werkcv-salaris-tools/`

## 5. Checkout the WordPress.org SVN repo

Example:

```powershell
svn checkout https://plugins.svn.wordpress.org/werkcv-salaris-tools D:\wp-svn\werkcv-salaris-tools
```

Expected directories:

- `trunk/`
- `tags/`
- `assets/`

## 6. Prepare the working copy

```powershell
powershell -ExecutionPolicy Bypass -File .\wordpress-plugin\prepare-svn-working-copy.ps1 -WorkingCopyPath D:\wp-svn\werkcv-salaris-tools
```

This stages:

- plugin code into `trunk/`
- version snapshot into `tags/0.1.1/`
- WordPress.org artwork into `assets/`

## 7. Review before commit

Check:

- `trunk/` contains the plugin code
- `assets/` contains only WordPress.org assets:
  - `icon-128x128.png`
  - `icon-256x256.png`
  - `banner-772x250.png`
  - `banner-1544x500.png`
  - `screenshot-1.png` to `screenshot-4.png`
- no `node_modules/`
- no plugin-directory banners/icons inside `trunk/`

## 8. Add and commit

```powershell
cd D:\wp-svn\werkcv-salaris-tools
svn add --force trunk assets tags
svn status
svn commit -m "Release 0.1.1"
```

## 9. Verify after commit

Check:

- plugin page loads
- screenshots/icons appear after cache delay
- install zip generated by WordPress.org does not include banners/icons

## Notes

- The plugin package no longer includes WordPress.org directory assets.
- Screenshots were also moved out of the plugin download and into SVN `assets/`.
- If you change plugin code later, update:
  - plugin header version
  - `WERKCV_SALARIS_TOOLS_VERSION`
  - `Stable tag` in `readme.txt`
  - create a matching new `tags/x.y.z/`
